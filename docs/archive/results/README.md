# Historical research outputs

`legacy-matches.csv` and `legacy-bets.csv` are the former root CSV outputs.
They contain 9,158 predictions and 926 selections and differ from the published
9,157-prediction / 925-selection snapshot. They are retained as research history,
not inputs for reproducing or publishing the current website. Some values and
prices differ; the historical full-precision website run cannot be recovered
exactly from these files.

Other outputs in this directory are earlier experiments. They are not current
website evidence. Use `frontend/public/data/` and its run manifest for that.
