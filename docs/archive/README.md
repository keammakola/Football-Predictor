# Historical project material

These files preserve earlier planning, design proposals, prototype manifests,
and experiment outputs. They describe past versions and are not the current
setup instructions or evidence for the website's results.

- `planning/`: original milestones, investigations, and discussions.
- `design-notes/`: the earlier Margin X-Ray frontend proposal.
- `frontend-prototypes/`: abandoned alternative frontend prototypes.
- `results/`: earlier console output and experiment notes, retained for context.
- `original-project-overview.md` and `original-model-methodology.md`: earlier
  descriptions of the modelling approach.

Use the root README for current commands, `docs/xg-data.md` for the current xG
pipeline, and `frontend/public/data/provenance.json` for the website's exports.
