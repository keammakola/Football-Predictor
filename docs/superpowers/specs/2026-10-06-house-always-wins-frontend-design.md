# Frontend Specification: The House Always Wins

## 1. Product Summary
**One line:** A free tool that shows what betting really costs, using every prediction a real model has made, the odds on offer and the results.
**Core message:** Being right is not enough, because price decides profit.
**Audience:** Curious bettors, students, data journalists, consumer-protection organizations.
**Principles:** Honest over persuasive, Price first, Verifiable, No tips, Calm editorial look, Plain language.

## 2. Design System & Anti-Tropes (per frontend-design skill)

### Look and Feel
Editorial data journalism. Warm off-white paper, dark ink, thin rules instead of shadows. No casino imagery.
*Anti-trope enforcement:* Zero drop-shadows (no SaaS-card kits). No tracked-out ALL-CAPS eyebrows. No generic fade-and-slide motion.

### Color Tokens
*   `--bg`: `#FAFAF7` (Page background)
*   `--surface`: `#FFFFFF` (Cards, tables)
*   `--ink`: `#16181B` (Body text)
*   `--muted`: `#5B6168` (Secondary text)
*   `--line`: `#E4E4DF` (Rules and borders)
*   `--accent`: `#2457D6` (Links, focus rings)
*   `--hit`: `#0F6CBD` (Prediction was right - functional marker)
*   `--miss`: `#C2410C` (Prediction was wrong - functional marker)
*   `--cost`: `#7C3AED` (Margin / cost of bet - functional marker)
*   `--warn`: `#8A6100` (Small-sample / stale data notices)

### Typography
*   **Headings:** `Source Serif 4`, fallback Georgia.
*   **Body:** `Inter`, fallback system-ui.
*   **Data:** `font-variant-numeric: tabular-nums` globally applied to all tables/charts.
*   *Anti-trope enforcement:* No mixing bold/italic randomly in headlines to seem "designed". Headings are strictly structural.

### Space, Grid, and Layout
*   Base unit: 4px. Max-width: 1120px. Prose width: 680px.
*   Alignment: Strictly left-aligned data flows. No centered text blocks.
*   Borders: 1px solid `--line`. Radius: 6px for inputs, 10px for cards.

## 3. Data Contracts
JSON files generated by Python backend:
- `predictions-all.json`
- `scoreboard.json`
- `fixtures.json`
*(Static schema without backend dependencies)*

## 4. Key Components & Pages
1. **Margin X-ray:** Interactive calculator mapping raw odds to overround and fair probabilities.
2. **Predictions Ledger:** Complete history of bets with break-even vs offered odds.
3. **Scoreboard:** Model vs Market Log Loss, Calibration Chart, Cumulative Profit.
4. **Simulators:** "Skill vs Luck" and "Why a 60% pick loses" interactives.

## 5. Technology Stack
*   **Framework:** Astro / React (or Vite/React if Astro networking is unavailable)
*   **Styling:** Tailwind CSS (customized with CSS variable tokens)
*   **Data Visualization:** Observable Plot or D3.js
